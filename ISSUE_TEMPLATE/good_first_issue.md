## How to Get Started

Welcome to NEXORA! This issue is specifically crafted for students making their first open-source contribution.

1. **Claim this Issue**: Comment below with `"I would like to work on this issue!"` so a `technical-team` mentor can assign it to you.
2. **Review Guides**: Read our [GITHUB-BEGINNER-GUIDE.md](../docs/GITHUB-BEGINNER-GUIDE.md) and [CONTRIBUTING.md](../CONTRIBUTING.md).
3. **Branch Name**: Use `feature/<short-desc>` or `fix/<short-desc>`.
4. **Need Help?**: Tag `@NEXORA-VIIT-ORG/technical-team` or comment directly on this issue if you get stuck at any step!
