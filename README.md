# NEXORA Student Chapter – VIIT

Welcome to the central `.github` configuration repository for **NEXORA Student Chapter – VIIT**.

This repository hosts organization-wide community health files, standards, issue/PR templates, and guidelines that apply across all projects within the `NEXORA-VIIT-ORG` GitHub organization.

## Purpose of this Repository

The primary goal of this repository is to establish a structured, beginner-friendly, and educational environment for students at Vishwakarma Institute of Information Technology (VIIT) to learn Git, GitHub, open-source practices, and collaborative software development.
